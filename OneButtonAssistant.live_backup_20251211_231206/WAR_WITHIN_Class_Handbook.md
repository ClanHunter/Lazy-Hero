# War Within — Class Handbook

This handbook compiles the class-by-class summaries provided during the session: core abilities, class talent trees, spec cores/talents, and Hero talents.

## 1. Death Knight
Core Abilities (all specs)
- Death Grip
- Death Coil
- Death Strike
- Raise Dead
- Anti-Magic Shell
- Icebound Fortitude

Spec Talent Trees
- Blood (Tank): Heart Strike, Marrowrend, Death Strike, Vampiric Blood, Dancing Rune Weapon
  - Talents / examples: Bone Shield maintenance, Marrowrend for bone shield stacks, Vampiric Blood defensive spacing
- Frost (DPS): Obliterate, Frost Strike, Howling Blast, Pillar of Frost
  - Talents / examples: Runic Empowerment, Frost rune management, Frostscythe/Execute interactions
- Unholy (DPS): Festering Strike, Scourge Strike, Gorefiend's Grasp, Apocalypse, Army of the Dead
  - Talents / examples: Disease management (Outbreak), Festering wounds, pet/disease buffs

Hero Talents (War Within)
- San'layn: vampiric shadow enhancements and bleed synergy
- Rider of the Apocalypse: empowered mounted abilities and corpse-driven mechanics
- Deathbringer: execution-focused burst rotation talents

PvP Talents (examples)
- Necrotic Wounds, Dark Simulacrum, Strangulate, Death Chain, Necrotic Aura
